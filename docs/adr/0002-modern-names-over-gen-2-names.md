# Modern names win over Gen 2 names

When Kristall's official name for something differs from the one in current German games, the translation uses the Modern name. Polished Crystal already uses modern English names and modern mechanics, so modern German names keep the translation consistent with its source text and with what players know from current games.

## Consequences

- Kristall's dialogue can't be reused verbatim wherever it mentions something that was later renamed.
- Some Modern names exceed a Name limit. Those get an Abbreviation, chosen once and reused everywhere.

## Amendment (2026-11-18)

When a Modern name is over its Name limit and Kristall has its own name for the same thing, Kristall's name wins over an Abbreviation (Giftblick, Hackattack, Türöffner …). Single further exceptions are the user's choice and listed in `TERMS.md` (Hagelalarm, the X items' Gen 4–6 set, Detektor, Seegesang, Liftöffner).
