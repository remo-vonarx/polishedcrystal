# Polished Crystal: German Translation

The German version of Polished Crystal, made in a fork that tracks the English Upstream and played as a Virtual Console title on a New 3DS.

## Sources

**Upstream**:
The English Polished Crystal (Rangi42/polishedcrystal), which this fork tracks and translates.
_Avoid_: original, base game

**Kristall**:
Pokémon Kristall-Edition, the official German release of Pokémon Crystal. Its text is the German for every line Upstream kept from Crystal.
_Avoid_: German Crystal, the original

**Translation**:
The German version this project produces, in both ROMs (Regular and Faithful).
_Avoid_: localization, port

**Own translation**:
German written for this project where neither Kristall nor a later official German game has the text; always flagged for review.
_Avoid_: free translation, adaptation

## Letters

**Umlauts**:
Ä ä Ö ö Ü ü. Every font of the Translation draws them, and the naming keyboards offer them.

**ß**:
Written as Kristall writes it (mostly the new spelling: Straße, but dass; a few older forms such as erfaßt), and in Own translation as the new spelling has it. The naming keyboards have no ß key, as in Kristall.

## Pokémon

**Pokémon names**:
Kristall's names for the 251 Pokémon of Gen 2, in mixed case (BISASAM → Bisasam), and today's official German names for Polished's later ones (Pantifrost, Dummimisel). An Egg is an Ei, a Bad Egg a Schl. Ei (Emerald's form).
_Avoid_: Kristall's capitals in tables

**Drache**:
The Dragon type and the Dragon egg group, as the games write it since Gen 4.
_Avoid_: Drachen (Kristall's name for the type)

**Abilities**:
The official German names from before Gen 9, the era of Polished's mechanics: Tempomacher (Own Tempo), Fußangel (Tangled Feet), Aufheber (Poison Heal), Hagelalarm (Snow Warning, which summons hail in Polished).
_Avoid_: Gleichmut, Taumelschritt, Giftheilung, Schneeschauer

**Egg groups**:
The official German names (Monster, Feld, Humanotyp, Amorph, Unbekannt …); in Faithful also Wasser 1, Wasser 2, Wasser 3. Regular's own names for the water groups are an Own translation: Amphibie (Water 1), Fisch (Water 2), Wirbellos (Water 3).
_Avoid_: Wirbellose

**Type chart labels**:
The Type Chart screen names the attacker ANGR and the defender VER (Kristall's forms) and heads its columns NRML, KAMPF, FLUG, GIFT, BODEN, GEST, KÄFR, GEIS, STHL, FEUR, WASR, PFL, ELEK, PSYC, EIS, DRCH, UNLI, FEE.

## Moves

**Move names**:
Kristall's names for the moves of Gen 2, in mixed case (DONNERBLITZ → Donnerblitz), and today's official German names for Polished's later ones. Where a Kristall name was renamed later, the choice per move is: Konfusstrahl, Staffette, Giftblick, Schnabel, Wandler, Gesichte.
_Avoid_: Konfustrahl, Stafette, Schlangenblick, Pikser, Verwandler, Scharfblick

**Wertewechsel**:
Skill Swap, by its official name from Gen 3 to 7; today's name doesn't fit the 12-character limit.
_Avoid_: Fähigkeitstausch

**Säuselstimme**:
Disarming Voice (in Polished's English squeezed to "Disarm Voice").

**Frischsnack**, **Furienhieb**, **Heillicht**:
Own translations of Polished's own moves: Fresh Snack (replaces Milchgetränk and Weichei), Fury Strikes (replaces Furienschlag and Kratzfurie), Healing Light (replaces Mondschein, Morgengrauen and Synthese).
_Avoid_: Furienhiebe, Lichtheilung

**VM**:
An HM is a VM (Versteckte Maschine), as in Kristall: VM01. A TM stays a TM.
_Avoid_: HM
