# Polished Crystal: German Translation

A German-language version of Polished Crystal, built from a fork that tracks the English upstream and played on a New 3DS through Virtual Console.

## Projects and sources

**Upstream**:
The English Polished Crystal project (Rangi42/polishedcrystal), which this fork tracks and translates.
_Avoid_: original, main repo, base game

**Translation**:
The German-language version of Polished Crystal that this project produces.
_Avoid_: localization, port, German hack

**Kristall**:
The official German release of Pokémon Crystal, on cartridge and on Virtual Console. It is the reference for Gen 2 names and dialogue.
_Avoid_: German Crystal, Kristall ROM

**Source text**:
The English upstream text that a passage of the translation is translated from.
_Avoid_: original text, English text

**Original content**:
Story, characters, places and dialogue that Polished Crystal invented. No official German version exists.
_Avoid_: custom content, fan content, new content

**Faithful**:
The upstream build variant that keeps canon types, stats and abilities. Its counterpart is **Non-Faithful**, which uses Polished Crystal's rebalanced data.
_Avoid_: vanilla, canon mode

## Names

**Official name**:
A German name published by Nintendo or The Pokémon Company for a Pokémon, move, item, ability, place, character or trainer class.
_Avoid_: canon name, real name

**Gen 2 name**:
The official name as it appears in Kristall.
_Avoid_: old name, classic name

**Modern name**:
The official name as it appears in current German Pokémon games.
_Avoid_: new name, current name

**Anime name**:
A name from the German anime dub, for things that have no official name from the games.
_Avoid_: dub name, TV name

**Name limit**:
The most characters the game can display for one category of name, such as Pokémon, move, item, trainer class or player.
_Avoid_: max length, character limit

**Abbreviation**:
A shortened official name that fits a name limit. It is chosen once and reused everywhere.
_Avoid_: short name, truncation

**Character set**:
The fixed set of characters the game can display. It includes ä, ö, ü, Ä, Ö and Ü; ß is written as "ss".
_Avoid_: font, alphabet, charmap

## Platform

**Virtual Console**:
Nintendo's Game Boy and Game Boy Color emulator on the 3DS, which is the translation's target platform.
_Avoid_: VC game, 3DS emulator

**Base CIA**:
A dumped Crystal Virtual Console title from the player's own console. Its emulator and metadata are reused and its ROM is thrown away.
_Avoid_: Kristall ROM, template, original game

**VC patch**:
The per-build file that tells Virtual Console how to handle link features for this specific ROM.
_Avoid_: patch (unqualified)

**MBC30 patch**:
A one-byte change to the Virtual Console emulator that lets it reach ROMs larger than 2 MB.
_Avoid_: patch (unqualified), 4 MB fix

**Distribution patch**:
The patch file players apply to their own ROM to get the translation.
_Avoid_: patch (unqualified), IPS, hack file

**ROM space**:
The fixed capacity that all of the translation's text, graphics, audio and code must fit into.
_Avoid_: free space, storage
